### ✨ Главные нововведения

#### 1. 🧙‍♂️ Мастер первого запуска (Onboarding Wizard)
- **Авторизация в 1 клик**: Вход через GitHub OAuth Device Code Flow (код автоматически копируется в буфер обмена).
- **Выбор рабочей папки**: Быстрый выбор каталога с отображением свободного места на диске.
- **Интеграция с ИИ**: Автоматический поиск запущенного сервера **Ollama** и выбор моделей (`llama3.2`, `mistral`), либо ввод ключей **DeepSeek / OpenAI**.
- **Быстрые пресеты**: Популярные шаблоны поиска ("AI библиотеки", "Парсеры", "Telegram боты").

#### 2. 🔄 Встроенная система автообновлений
- Проверка наличия новых версий прямо из приложения (`Справка -> Проверить обновления...`).
- Загрузка и бесшовная замена файлов в 1 клик без блокировки Windows.
- Поддержка командной строки: `python app.py --check-updates` и `python app.py --version`.

#### 3. 📊 Информационный статус-бар
- В шапке окна отображается:
  - 🟢 Логин GitHub и оставшийся лимит API запросов (например, `4998/5000`);
  - 🤖 Статус и модель AI;
  - 💾 Свободное место на целевом диске.

#### 4. 🤖 Экспорт для AI (Repomix XML)
- Упаковка структуры и содержимого репозитория в единый структурированный XML-документ для быстрой загрузки в LLM.

#### 5. 🛡️ Усиление безопасности
- Защита от symlink-петель (CWE-59).
- Защита от инъекций аргументов командной строки `git clone` (CWE-88).
- Защита от инъекций формул CSV/Excel (CWE-1236).
- Хранение токенов в зашифрованном виде через Windows DPAPI.
